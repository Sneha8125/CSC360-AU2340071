Reflection: Programming Concepts, GUI Components and Event Handling

1. Reflection in programming languages
I learned that reflection is a programming technique that allows a program to examine information about itself, such as classes, methods, fields, and objects, during runtime. It provides flexibility because program components can be identified and used dynamically.

2. Reflection in Java
In Java, reflection is provided through the java.lang.reflect package and classes such as Class, Method, Field, and Constructor. It allows a program to inspect and access class information at runtime. It is useful in frameworks, testing tools, and applications that need dynamic behavior.

3. Exceptions in programming
An exception is an unexpected condition or error that occurs while a program is executing. Exceptions help a program handle errors in a controlled manner instead of terminating unexpectedly.

Uses:
- Handling runtime errors safely.
- Providing meaningful error messages to users.
- Maintaining the normal flow of a program where possible.
- Separating error-handling code from the main program logic.

4. Runtime Exceptions and Checked Exceptions
Runtime exceptions occur during program execution and are generally caused by programming or logical errors, such as dividing by zero or accessing an invalid array index. Examples include ArithmeticException and NullPointerException.

Checked exceptions are checked by the compiler and must be handled using try-catch or declared using throws. Examples include IOException and SQLException.

5. How exceptions are shown on software
Exceptions can be presented to users through error messages, alert boxes, notifications, or error pages. In development environments, detailed exception information such as the exception type and stack trace may also be displayed to help developers identify the problem.

6. Generic Programming
Generic programming allows classes, methods, and data structures to work with different data types while maintaining type safety. In Java, generics are commonly written using type parameters such as <T>. They reduce the need for type casting and help detect type-related errors during compilation.

7. Collection and its examples
A collection is an object used to store and manage a group of objects. Java provides the Collection Framework for handling data efficiently. Examples include ArrayList, LinkedList, HashSet, TreeSet, and Queue implementations such as PriorityQueue.

8. Views as read-only data
A view can provide a read-only representation of data without allowing the underlying data to be directly modified through that view. In databases, a view is a virtual table created from a query and can be used to restrict access to selected data. This improves data security and simplifies access to complex data.

9. Opposite to graphics - console
The console is a text-based interface where input and output are represented using characters rather than graphical elements. Graphics and GUI applications use visual components such as windows, buttons, and images, while console applications primarily use text.

10. How event handling is connected to graphics or GUI
Event handling allows a GUI application to respond to user actions such as mouse clicks, key presses, and mouse movements. When an event occurs, an event handler executes the required action, which may change or redraw graphical elements.

11. What if there is no event? Does it mean there is no graphics?
No. Graphics can exist even when there is no user event. Events are responsible for interaction and changes in the GUI, while graphics can be displayed independently. For example, a static image can be shown without any user interaction.

12. Event hierarchy and what it is
Event hierarchy refers to the organization and flow of events and their related classes in a GUI framework. In Java, events are represented through a hierarchy of event classes, with higher-level classes providing common properties and specialized classes representing specific events. This structure makes event handling organized and reusable.

13. Source in an event
The source is the GUI component that generates an event. For example, when a button is clicked, the button is the event source. The event object contains information about the event, and the listener handles the required response.

14. Difference between checkbox and radio button
A checkbox allows the user to select multiple options independently. A radio button is generally used when the user must select only one option from a group. For example, multiple hobbies can be selected using checkboxes, while one payment method can be selected using radio buttons.

15. Slider, its uses and advantages
A slider is a GUI control that allows the user to select a value from a range by moving a handle along a track. It is commonly used for volume, brightness, zoom, and other adjustable values.

Its main advantage is that it provides a quick and intuitive way to select a value without requiring the user to type it manually.

16. Importance and use of dialogue boxes
A dialogue box is a GUI component used to communicate important information or obtain a decision from the user. It can display messages, request input, or ask for confirmation. Its main importance is that it captures the user's attention and can require a response before continuing with an important action.

17. Master-Detail Layout
A Master-Detail Layout displays a list or collection of items in one section and the details of the selected item in another section. For example, an email application can show a list of emails on one side and the content of the selected email on the other. This layout helps users navigate and understand related information efficiently.
