## Reflection - Debugging, Organization and GitHub Progress


1. Running the Project through Maven
   - On the second day, I ran the JavaFX project through Maven to verify whether the application was compiling correctly.

2. Debugging Java Naming Issues
   - One of the main issues identified was that some public class names did not match their corresponding filenames.
   - The file `main.java` was renamed to `Main.java`, and `controlPanel.java` was renamed to `ControlPanel.java`.
   - This was important because Java requires a public class name to match the name of its source file.
   - Fixing these naming issues helped me understand how Java naming conventions directly affect compilation.
