## Reflection - JavaFX Project Foundation

1. JavaFX Application Foundation using Maven
   - Started the project by setting up the JavaFX application using Maven.
   - Maven was used to manage the project structure and JavaFX dependencies in an organized way.
   - This helped establish a proper foundation for the application and made the project easier to build and maintain.
   - Through this step, I understood how Maven can be used to manage dependencies instead of manually configuring JavaFX libraries.

2. Creating the Main Application Structure
   - Created the main JavaFX application class and worked with the basic JavaFX components such as Stage, Scene, and BorderPane.
   - The Stage represents the main application window, while the Scene contains the user interface displayed inside the window.
   - BorderPane was used as the main layout because it provides different regions for organizing the interface.
   - This helped me understand the basic structure of a JavaFX application and how different UI components are placed inside a scene.

3. Establishing the Application Window
   - Created the initial application window with an appropriate width and height.
   - Minimum dimensions were also defined so that the interface does not become too small when the window is resized.
   - This was important for creating a usable interface and provided a foundation for making the application responsive.

4. Creating the Initial Left Control Panel
   - Created the initial structure of the left-side control panel.
   - The control panel will later contain the controls required to modify the properties of the geometric object.
   - Separating the controls from the preview area makes the application easier to understand and provides a clear workspace for styling the object.

5. Creating the Right-Side Preview Area
   - Created the right-side preview area using StackPane.
   - The preview area will be used to display the geometric object and show the changes made through the control panel.
   - StackPane was selected because it allows the object to be positioned and displayed conveniently within the preview region.

6. Dividing the Control Panel into Sections
   - Organized the control panel into four initial sections: Object, Position, Transformation, and Appearance.
   - The Object section will be used for selecting or managing the geometric object.
   - The Position section will contain controls related to the object's location.
   - The Transformation section will be used for properties such as size, rotation, and scale.
   - The Appearance section will later contain styling properties such as fill, stroke, and opacity.
   - Dividing the controls into logical sections makes the interface more structured and easier to use.

7. Adding Placeholder Labels
   - Added placeholder labels to establish the initial hierarchy of the user interface.
   - These labels helped define where different controls will be placed as the project develops.
   - This also provided a clear visual structure before implementing the complete functionality of each section.

8. Creating the JavaFX CSS File
   - Created an initial `style.css` file for styling the JavaFX application.
   - Separating styling from Java code makes the project more organized and allows the appearance of UI components to be changed without modifying the main application logic.
   - This provided the foundation for further UI customization in the later stages of the project.

9. Applying Basic UI Styling
   - Applied basic styling to improve the appearance and readability of the application.
   - Background colors were added to distinguish different areas of the interface.
   - Panel borders were used to visually separate sections.
   - Font sizes, font weights, and text colors were adjusted to create a clear hierarchy between headings and other text.
   - Padding and spacing were added to prevent the interface from appearing crowded.
   - These changes helped me understand how JavaFX CSS can be used to control the visual appearance of UI components.

10. Organizing the Project into Separate UI Classes
   - Worked on separating the user interface into different classes instead of keeping all the code inside the main application class.
   - This makes the project easier to read, maintain, and extend as more features are added.
   - It also provides a better separation of responsibilities between different parts of the application.
   - This approach will be useful in the upcoming stages when more controls and functionality are introduced.

## Overall Learning

- Day 1 mainly focused on creating a strong foundation for the JavaFX project rather than implementing the complete functionality.
- I gained a better understanding of the relationship between Stage, Scene, layouts, and UI components in JavaFX.
- I also learned the importance of planning the UI structure before adding complex functionality.
- Using Maven and CSS helped me understand how dependencies and styling can be managed separately from the application logic.
- Organizing the application into separate classes will make it easier to work on individual features and maintain the project as it grows.
- The initial foundation created on Day 1 will be used for implementing object creation, transformations, styling controls, and user interactions in the next stages.
