## Understanding Upstream:
Upstream can be understood in the context of Git and version control. Upstream is the connection that exists between the local branch and the remote branch for the same. Upstream connection is helpful to git in determining which remote branch will be used in commands like git push and git pull.

## .gitignore and Project Files:
I grasped the significance of the .gitignore file in any software development process. The .gitignore file specifies to Git what files and directories it must not track or push to the GitHub account. Files and directories like .iml files, out directories, and .idea directories contain specific IDE data or are generated and thus do not need to be included.

## Threads and Processes:
I was introduced to the differences between processes and threads. Process refers to a running program while thread refers to one path of execution within that program. Creation of a thread enables a program to do some other task simultaneously. I realized that the problem with simultaneous reading was not much but with simultaneous writing as there could be conflict among different threads to change the same value.

## Swing Is Not Thread-Safe:
I discovered that Java Swing is not thread-safe since its GUI components are not built in a manner that would enable them to be manipulated by more than one thread at once. When two threads manipulate the same component at once, they may get into conflict and lead to unpredictable results.

## The Reason for Single-threading in GUI Operations:
GUI operations are carried out through the Event Dispatch Thread (EDT) in Swing. The use of the dedicated thread ensures that only one thread manipulates the GUI components at once.

## Freezing of GUI:
Through my learning, I got to know that it happens due to the GUI getting frozen when a lengthy process is done in the GUI thread. For instance, if any lengthy process or calculation is done by the Event Dispatch Thread, then it will not be able to respond to user input and repaint the display.
