- A terminal can also be used to connect to a remote computer through SSH, which shows how text-based interfaces can be useful even when a graphical interface is not available.

3. Splash Screen and FXML

- I learned about the concept of a splash screen in a graphical application.
- A splash screen is usually displayed when an application is starting and provides the user with basic information while the application loads.
- I understood that a splash screen can improve the user experience by giving feedback instead of leaving the user with an apparently inactive screen.

4. Tree of Objects and Object Editing

- I learned about a tree-based representation of objects where each object can be represented as a node in a hierarchy.
- The main idea was to create a tree of objects while also providing support for editing the properties of each individual object.
- This concept helped me connect the idea of a data structure with a practical graphical application.
- I learned that an object represents a specific entity containing data and possibly behavior associated with it.
- Files and folders are useful examples of hierarchical objects because folders can contain other folders and files.
- This naturally forms a tree structure in which folders act as parent nodes and files or subfolders act as child nodes.
- I understood that editing an object in such a system means changing its properties while maintaining its position and relationship within the overall structure.
- This type of object tree can be useful in applications such as file explorers, editors, design tools, and other systems where hierarchical information needs to be displayed and modified.

5. Serialization

- I was introduced to the concept of serialization as a way of saving objects that exist in memory.
- An object in memory normally exists only while the program is running unless its information is stored somewhere.
- Serialization provides a way to convert the state of an object into a form that can be stored and later reconstructed.
- I understood that this is useful when an application needs to save its current state and restore it later.
- The concept is particularly relevant to an object tree where multiple objects and their relationships may need to be saved.
- This helped me understand how the objects created during program execution can be preserved instead of being lost when the program terminates.

6. Composite Processor and Multiple Jobs

- I learned about the concept of a composite processor that can track and manage multiple jobs.
- The main purpose is to allow a system to handle several tasks while maintaining information about their progress and state.
- I understood that managing multiple jobs becomes more complex when the user or system needs to cancel one or more of those jobs.
- The processor therefore needs to keep track of the tasks and provide a mechanism for controlling their execution.
- This connected the discussion with thread management because different jobs may be executed using different threads.
- The concept showed me how larger applications need a structured way to manage multiple independent operations.

7. Thread Cancellation and Cleanup

- I learned about thread cancellation and why it is important when a running task is no longer required.
- Cancellation is useful for programs where users may stop an operation before it has finished.
- I understood that cancelling a thread does not simply mean stopping it immediately without considering its current state.
- A program may need to give the thread enough time to finish or clean up the resources it is currently using.
- Proper cleanup is important because a cancelled task may otherwise leave files, memory, connections, or other resources in an inconsistent state.
- This showed me why thread management requires careful handling rather than simply starting threads without considering how they will end.
- The discussion helped me understand that allowing a thread to wrap up its work safely can make a program more reliable and easier to maintain.
- Thread cancellation becomes especially important in applications that manage multiple jobs simultaneously.
